# Mapa de Riesgo

Visor interactivo de riesgo con capas de distritos, zonas de alto riesgo
y pronóstico de precipitación acumulada 72 h.

## Estructura

- `datos/` — capas vectoriales y metadata
- `scripts/` — scripts Python de procesamiento
- `tiles_pronostico/` — teselas XYZ del pronóstico
- `index.html` — visor web
